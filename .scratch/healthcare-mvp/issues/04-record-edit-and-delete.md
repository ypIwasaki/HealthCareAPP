# 04: 既存記録を編集・削除する

Status: ready-for-agent

**Parent:** 個人向けヘルスケアアプリ初版 — 体重記録と振り返り（healthcare-mvp）

**What to build:** 同じ測定日を選ぶと既存内容を表示し、一覧からも編集・削除できるようにする。確定する前に取り消せる操作にする。

**Blocked by:** 03: 体重記録を保存し、自動計算付きの一覧で確認する

**対応する完成条件:** AC-03、AC-04、AC-05（記録編集）

## 完了条件

- [ ] 同日の既存内容を表示して編集でき、保存しても件数が増えない。一覧から過去の体重記録を開ける。
- [ ] 編集時も新規登録と同じ必須・日付・数値・一意性の検証を行う。
- [ ] 通常編集では記録の計算用身長を保持し、編集後の記録から BMI と換算値を再計算する。
- [ ] 保存前のキャンセル・検証失敗・保存失敗で元の体重記録が変わらない。
- [ ] 削除前に対象を示して確認し、キャンセルでは保持、確定時は削除する。編集・削除の結果は一覧と再読み込みに反映する。

## 共通の完了条件

- [ ] 画面操作から結果表示まで、この Issue の範囲を実際に動作確認し、確認結果を残す。
- [ ] 保存を伴う処理は Controller が呼ぶ共通の公開処理を境界として、一時 SQLite DB で保存・再読み込み・失敗時の保持を検証する。内部の呼び出し回数や SQL 文字列を合否の基準にしない。
- [ ] 変更内容・各部分の役割・コードを読む入口と順番・確認方法を短く文書化する。MVC と専用の保存処理の責任分担を守り、必要な機能だけを増やす。
