# 10: 管理画面から設定を確認・編集する

Status: ready-for-agent

**Parent:** 個人向けヘルスケアアプリ初版 — 体重記録と振り返り（healthcare-mvp）

**What to build:** 身長設定と2つの換算設定を管理画面で表形式に確認・編集し、通常の設定画面と同じ保存結果を得られるようにする。

**Blocked by:** 09: 管理画面から記録行を操作する

**対応する完成条件:** AC-09（設定）、AC-05〜AC-07（管理経路）

## 完了条件

- [ ] 身長設定と2式の既定の設定行を表形式で表示して編集できる。設定行の追加・削除を提供しない。
- [ ] 通常設定画面と同じ公開処理・入力検証・保存失敗時の保持ルールを使う。
- [ ] 身長設定の変更では過去の計算用身長と BMI を保持し、新規記録にだけ新しい身長を使う。
- [ ] 換算式の変更は全既存記録を検証して保存し、過去を含む換算値と関連画面へ反映する。
- [ ] スキーマ情報・内部 ID・自動計算結果の編集を提供せず、再読み込み後も通常画面と同じ設定を取得できる。

## 共通の完了条件

- [ ] 画面操作から結果表示まで、この Issue の範囲を実際に動作確認し、確認結果を残す。
- [ ] 保存を伴う処理は Controller が呼ぶ共通の公開処理を境界として、一時 SQLite DB で保存・再読み込み・失敗時の保持を検証する。内部の呼び出し回数や SQL 文字列を合否の基準にしない。
- [ ] 変更内容・各部分の役割・コードを読む入口と順番・確認方法を短く文書化する。MVC と専用の保存処理の責任分担を守り、必要な機能だけを増やす。
