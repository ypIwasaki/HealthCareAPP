# 11: 手動バックアップを保存する

Status: ready-for-agent

**Parent:** 個人向けヘルスケアアプリ初版 — 体重記録と振り返り（healthcare-mvp）

**What to build:** ファイル選択画面で保存先を指定し、体重記録と設定をまとめたバックアップを手動保存できるようにする。

**Blocked by:** 05: 換算式を編集・保存し、過去分へ適用する

**対応する完成条件:** AC-10（バックアップ取得）

## 完了条件

- [ ] SQLite のバックアップ機能で整合したファイルを生成し、稼働中 DB の単純なファイルコピーにはしない。
- [ ] 記録・各記録の計算用身長・現在の身長設定・有効な2式・対応形式を識別する情報を含める。
- [ ] 保存先を選択でき、既存ファイルへの上書きは確認する。
- [ ] キャンセル・保存失敗で稼働中の DB が変わらず、成功または失敗を利用者が把握できる。
- [ ] 一時 DB と生成したバックアップを使い、記録・設定・式が取得時点と一致し、ファイルを読み取れることを検証する。

## 共通の完了条件

- [ ] 画面操作から結果表示まで、この Issue の範囲を実際に動作確認し、確認結果を残す。
- [ ] 保存を伴う処理は Controller が呼ぶ共通の公開処理を境界として、一時 SQLite DB で保存・再読み込み・失敗時の保持を検証する。内部の呼び出し回数や SQL 文字列を合否の基準にしない。
- [ ] 変更内容・各部分の役割・コードを読む入口と順番・確認方法を短く文書化する。MVC と専用の保存処理の責任分担を守り、必要な機能だけを増やす。
